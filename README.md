# ⚡ PowerNova AI

AI-Based Electricity Consumption Forecasting & Anomaly Detection System

---

## 📌 Project Overview

PowerNova AI is a real-time electricity monitoring and analytics dashboard built using Python and Streamlit.

The system simulates IoT smart meter data, stores readings in a database, predicts future electricity consumption using AI models, and detects abnormal electricity usage.

---

## 🚀 Features

✅ Real-time electricity monitoring  
✅ Smart meter simulation  
✅ AI-based electricity forecasting  
✅ Anomaly detection system  
✅ Interactive analytics dashboard  
✅ Live graphs and charts  
✅ SQLite database integration  
✅ Multi-page Streamlit application  
✅ Dark futuristic UI

## ⚙️ How to Run

### 1. Clone Repository

```bash
git clone https://github.com/varshinivarshv2005-hub/PowerNova-AI.git
```

### 2. Install Requirements

```bash
pip install -r requirements.txt
```

### 3. Run Streamlit App

```bash
streamlit run app.py
```
